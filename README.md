# mobil_proje
Yapay zekâ destekli İngilizce öğrenme uygulaması, kullanıcıların dil becerilerini analiz ederek seviyelerine ve ihtiyaçlarına özel öğrenme planları oluşturur. Konuşma ve yazma pratikleri, akıllı kelime tekrarları ve gelişim takibiyle kişiselleştirilmiş, etkileşimli ve sürdürülebilir bir öğrenme deneyimi sunmayı hedefler.
